# Quiz App 🎯

An interactive Quiz Application built using HTML, CSS, and JavaScript. Test your knowledge, answer questions, and track your score through a simple and user-friendly interface.
## 🌐 Live Demo

[View Live Demo](https://abdallah777777.github.io/Quiz-App/)
## ✨ Features

- Interactive multiple-choice questions.
- Dynamic question navigation.
- Instant answer feedback.
- Score calculation.
- Final results display.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- JSON

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   https://github.com/abdallah777777/Quiz-App/
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
